# assets

여기에 운영 기관 CI 파일을 `ci.svg` (또는 `ci.png`, `ci.jpg`) 이름으로 넣으면
빌드 시점에 `index.html` 헤더에 data URI 로 인라인됩니다. 사이트가 index.html
한 장으로 자족하는 구조라 외부 파일을 두지 않습니다.

- 우선순위: `ci.svg` → `ci.png` → `ci.jpg` → `ci.jpeg`
- 파일이 없으면 로고 없이 기관명 텍스트만 표시됩니다(빌드는 정상).
- 헤더에서 높이 26px 로 표시되므로, 래스터 이미지라면 고해상도(높이 52px 이상)를
  넣어야 선명합니다. 가능하면 SVG 를 권장합니다.
- 다크 모드에서도 읽히는지 확인하세요. 배경이 흰 로고는 어두운 배경에서 묻힐 수
  있습니다(그럴 땐 흰색/단색 반전 버전이 필요합니다).
